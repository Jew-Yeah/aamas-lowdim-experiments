# Независимая проверка переключения в двухфазной модели

**Переключение помогает относительно непрерывной быстрой ветви, но не превосходит самостоятельную блочную безопасную стратегию на полном горизонте.** В основном сценарии one-switch лучше block safe по среднему расстоянию до изменения среды и на 24.05% лучше fast only по итоговому расстоянию. При этом его итоговое расстояние существенно больше, чем у block safe, лагового ответа и окна. Результат смешанный; все контрольные методы и заранее заданные сценарии сохранены.

## Что зафиксировали до валидации

[Протокол](../../docs/two_phase_validation_protocol.json) и [запись предварительной фиксации](precommitment.json) сохранены до 800 валидационных эпизодов. Время фиксации: `2026-10-04T05:56:14.532111+00:00`; SHA-256 протокола: `9fafd7cce7c9250fbc3981bba40f792791937ab9903b2461dcbcb1f5c3c1930b`. Разработка использовала seeds 0–7, а валидация — все seeds 10000–10199, по 200 на каждый сценарий. Эпизоды не исключались; досрочной остановки или выбора выигрышного сценария не было. Это проверяемая локальная фиксация после исследовательской разработки, а не внешняя preregistration.

В каждом эпизоде T=65536 решений. Все пять методов получают один и тот же внешний путь. На первом раунде спрос нулевой. До фиксированной границы H повторяется один известный тип задач; его отношение требуемой мощности к доступной выбирается один раз на эпизод из Uniform[0.02,0.15]. После H каждый раунд добавляет новый ортогональный тип задач с эффективностью a из Uniform[0.5,1] и независимо выбранным отношением r. Для основного и позднего изменения r лежит в [0.85,1]; для слабого — в [0.5,0.85]. В стационарном контроле H=T, второй фазы нет.

В построенной модели распределения ресурса p лежит в [0,1], выигрыш равен `u=a*p-b`, где `b=a*r`. В геометрическом начале (a,b)=(1,0). Ответ `p_star=b/a` даёт нулевой выигрыш на **всей строгой целевой области**, включая ненаблюдавшиеся внутренние смеси: `S(Q)={0}`. Исходная блочная безопасная процедура и доказанный бюджет `G=6*T^(3/4)=24576` сохранены. Быстрая проекция использует исходную геометрию `conv{0,e_1,...,e_M}`; только вычисления выигрыша безопасной процедуры сжаты без потерь. Новые типы имеют разные функции выигрыша, в отличие от одинаковых по выигрышу меток прежнего стресс-теста. Прикладная интерпретация синтетическая: реальные данные спроса и результаты внедрения здесь не измерялись.

Каждое решение принимается до текущего наблюдения. На раунде пересечения ещё работает быстрая ветвь; свежая безопасная процедура начинается со следующего решения. Периодических перезапусков нет. Лаговый ответ использует отношение из предыдущего контекста; окно — среднее не более 16 предыдущих отношений. Эти методы не знают H или будущие контексты. Для лагового ответа при неодинаковой эффективности телескопическая гарантия не заявляется.

## Метрики и все контрольные методы

`delta_t = abs(sum_{s<=t} u_s)/t` — точное расстояние до полной строгой цели. Метрика до изменения — среднее этого расстояния по каждому раунду до H; это не средняя мгновенная ошибка. Итоговая метрика равна delta_T. Средний дисбаланс за раунд — `mean(abs(u_t))`, дополнительная метрика, где ошибки противоположного знака не сокращаются. Для всех метрик меньше — лучше.

В таблицах указано **среднее ± стандартное отклонение по 200 независимым полным эпизодам**. Стандартное отклонение отражает различия эпизодов, а не неопределённость среднего. В стационарном контроле столбец «до H» охватывает весь горизонт. Каждый эпизод включён в опубликованные сводки. Фиксированные n=200 выбраны для приблизительно 80% мощности при стандартизованном парном эффекте 0,23, нормальном приближении и консервативном alpha=0,05/3; это не гарантирует мощности для практически важного абсолютного эффекта.

Малое расстояние среднего выигрыша может сочетаться со значительным дисбалансом за раунд из-за сокращения ошибок противоположного знака. Это видно в стационарном контроле: у fast only очень малое итоговое расстояние, но существенно больший дисбаланс за раунд, чем у лагового ответа и окна. Раннее преимущество по расстоянию до цели не означает лучшего отслеживания спроса на каждом решении.

## Три основных парных сравнения

Эти сравнения заранее заданы только для основного сценария. Каждая разность равна one-switch минус указанный метод: отрицательное значение в пользу one-switch. До изменения сравнивается среднее delta_t, в двух итоговых сравнениях — delta_T. Интервалы рассчитаны по парным различиям полных эпизодов; раунды не считались независимыми наблюдениями. Интервалы Bonferroni с отдельным уровнем 98,3333% дают консервативное семейное покрытие 95% для трёх средних; Holm корректирует двусторонние p-values в том же семействе. Процентильный bootstrap использует 9999 выборок целых эпизодов и фиксированный RNG из протокола.

| Сравнение | Парная разность | 95% t-интервал | 98,3333% интервал семейства | Победы / ничьи / поражения |
|---|---:|---|---|---:|
| До изменения: one-switch − block safe | -0.219079857 | [-0.222242347, -0.215917367] | [-0.222951889, -0.215207825] | 200 / 0 / 0 |
| Итог: one-switch − fast only | -0.125137787 | [-0.125200613, -0.125074961] | [-0.125214709, -0.125060865] | 200 / 0 / 0 |
| Итог: one-switch − block safe | 0.345494797 | [0.345461709, 0.345527884] | [0.345454286, 0.345535308] | 0 / 0 / 200 |

| Сравнение | 95% bootstrap-интервал | p после Holm | −log10 исходного p | Вывод в основном сценарии |
|---|---|---:|---:|---|
| До изменения: one-switch − block safe | [-0.222145598, -0.215952728] | 1.183e-198 | 197.93 | Преимущество перед block safe до изменения |
| Итог: one-switch − fast only | [-0.125200983, -0.125074951] | < 1e−300 | 487.75 | Преимущество перед fast only по итоговому расстоянию |
| Итог: one-switch − block safe | [0.345461619, 0.345527286] | < 1e−300 | 630.93 | Проигрыш block safe по итоговому расстоянию |

Два последних исходных p-values меньше диапазона обычного floating point: они **не равны математическому нулю**. В [analysis.json](analysis.json) сохранены конечные логарифмы p, `negative_log10_p_value` и явный флаг `p_value_underflow`. Запись `<1e−300` верна и после поправки Holm. В JSON также сохранены стандартные ошибки и стандартизованные парные эффекты d_z; очень большие d_z отражают малую вариативность внутри данного синтетического генератора.

Проверка механизма положительная: быстрая ветвь имеет раннее преимущество перед block safe, а последующее переключение улучшает итог относительно продолжения fast only. Отдельная гипотеза превосходства над safe only на полном горизонте не подтверждается: **one-switch проигрывает block safe во всех 200 основных эпизодах**. Лаговый ответ и окно также имеют меньшее раннее и итоговое расстояние в основном сценарии. Общего превосходства не заявляем.

## Переключения и заранее заданные проверки чувствительности

| Сценарий | Переключения | 95% интервал вероятности переключения | Квантили τ: 5% / 50% / 95% | Средняя длина безопасного хвоста |
|---|---:|---|---|---:|
| Основное изменение | 200 / 200 | [0.981725, 1.000000] | 51749.95 / 51808.00 / 51872.15 | 13729.58 |
| Позднее изменение | 0 / 200 | [0.000000, 0.018275] | — | 0.00 |
| Более слабое изменение | 200 / 200 | [0.981725, 1.000000] | 64840.85 / 64923.50 / 65007.15 | 613.16 |
| Стационарный контроль | 0 / 200 | [0.000000, 0.018275] | — | 0.00 |

Интервалы вероятности переключения — точные интервалы Clopper–Pearson по независимым индикаторам эпизодов. Квантили τ относятся только к состоявшимся переключениям; при оценке метрик используются все эпизоды, а знаменатель кривой переключений равен 200. В основном сценарии медианная задержка между изменением среды и пересечением бюджета составляет 35424 раунда: консервативный бюджет допускает значительную ошибку быстрой ветви до начала безопасного хвоста. В слабом сценарии переключение близко к концу горизонта и улучшение относительно fast only заметно меньше. В позднем сценарии ни один эпизод этой партии не переключился, поэтому one-switch совпадает с fast only. Проверки чувствительности описательные; дополнительных подтверждающих заявлений о значимости по ним нет.

И в позднем, и в стационарном сценариях парные разности one-switch минус fast only тождественно нулевые. Их t-статистики, p-values и d_z не определены и сохранены как `null`; фиктивная значимость не приписывается. Эмпирические интервалы вырождаются в ноль и явно отмечены как вырожденные. Все вычисленные гарантии безопасного хвоста выполняются, включая случаи без хвоста.

Вертикальный пунктир отмечает изменение среды, а не зависимый от данных момент переключения.

[Описание методов](../../docs/two_phase_validation_ru.md), [анализ](analysis.json) и четыре полные таблицы эпизодов ([основная](primary/episodes.json), [поздняя](late_change/episodes.json), [слабая](weaker_change/episodes.json), [стационарная](stationary_control/episodes.json)) сохраняют точные числа и все методы. В публичном репозитории находятся код, зафиксированные протокол и запись фиксации, сводки всех 800 эпизодов, анализ и графики. Большие массивы отдельных эпизодов на временной сетке и полные представительные пути сохранены локально и повторно генерируются runner; в компактную загрузку на GitHub они не включены. Seeds полных путей 10000 и 10001 выбраны до валидации, а не по удачным результатам.

```powershell
python -m pytest -q
python scripts/run_two_phase_validation.py --stage pilot --output results/two_phase_replay
python scripts/run_two_phase_validation.py --stage freeze --output results/two_phase_replay
python scripts/run_two_phase_validation.py --stage validation --output results/two_phase_replay
python scripts/run_two_phase_validation.py --stage analyze --output results/two_phase_replay
python scripts/run_two_phase_validation.py --stage figures --output results/two_phase_replay
```

Runner не перезаписывает завершённые эпизоды и отклоняет изменённые SHA исходников или протокола после фиксации. Для повторного запуска используйте новый выходной каталог. Статистический вывод относится только к заданному случайному генератору: он не доказывает репрезентативность для NYC, реальных противников, произвольных игр или показателей низкоразмерной сходимости. Зависимость от представления и позднее переключение при консервативном бюджете остаются существенными ограничениями.
