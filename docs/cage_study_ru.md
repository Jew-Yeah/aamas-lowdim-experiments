# Расширенная проверка на CAGE

Цель — точнее сравнить штатные потери симулятора после
[первого опыта](../results/cage_reference/README.ru.md). CAGE — среда проверки.
Сравниваемые методы включают её неизменённые агенты BlueMonitor,
BlueReactRemove и BlueReactRestore, три фиксированные пользовательские
политики, Hedge, ответ по последним 16 атакам и алгоритмы статьи.

[Локальный протокол](cage_study_protocol.json) фиксирует диапазоны seed,
основной показатель, сравнения и анализ до оценки новых банков эпизодов.
План сохранён в репозитории без внешнего сервиса предварительной регистрации.
Первый опыт использован для выбора дизайна и сохранён. Сбор данных не
останавливается при достижении статистической значимости.

## Основное сравнение

Зафиксированы исходные 40 обучающих таблиц seed и модель эпизода длиной
50 шагов. Собраны 400 новых проверочных таблиц, каждая для всех шести
защитных политик против трёх режимов атаки. Seed 32000000–32000399 не
пересекаются с исходными обучающими и проверочными seed.

Общий сценарий смены режимов содержит 512 метараундов и 50 новых seed
атакующего (36000000–36000049). В первой четверти работает Meander,
в средней половине появляются и случайно выбираются все режимы,
в последней четверти атакующий использует экспоненциальные веса,
обученные против фиксированной равномерной защиты. В основном сравнении
все методы встречают одинаковые траектории. Основной показатель — сумма
четырёх положительных компонентов штатных потерь в среднем за шаг симулятора.

Заранее выбраны шесть сравнений нашего метода: с наблюдением, реактивным
удалением, реактивным восстановлением, фиксированной политикой приманок
с реакцией, Hedge и ответом по окну. Отрицательная разность означает
меньшую потерю нашего метода.

## Единицы наблюдения и статистика

Каждый seed симулятора даёт полную таблицу потерь политик. Общий seed
сохраняет парность сравнений; политики расходуют случайные числа по-разному,
поэтому траектории эпизодов различаются. Каждый seed атакующего даёт
полную траекторию метаигры. Оценки 400 × 50 имеют перекрёстную зависимость
и не образуют 20000 независимых наблюдений симулятора.

В 10000 парных bootstrap-повторах независимо пересэмплируются целые
таблицы seed симулятора и целые траектории атакующего. Для всех шести
разностей используются одинаковые выборки. Такой подход соответствует
пересэмплированию строк и столбцов в
[pigeonhole bootstrap](https://arxiv.org/abs/0712.1111).

Перцентильные интервалы используют линейные квантили и уровень Бонферрони
0,05/6 для каждого сравнения. Преимущество в основном анализе считается
подтверждённым, если весь одновременный интервал лежит ниже нуля.
Также приведены приближённые двусторонние bootstrap p-value по
центрированным повторам с поправкой Холма на шесть сравнений. Эти процедуры
могут давать разные решения. Статистический вывод приближённый; точная
гарантия покрытия для конечной выборки не заявляется.

Интервалы условны на зафиксированную обучающую модель. Они учитывают
изменчивость новых seed симулятора и траекторий атакующего, но не
неопределённость калибровки. Ущерб безопасности и стоимость восстановления
являются дополнительными показателями и не заменяют основной показатель суммы.

## Проверки устойчивости

- Постоянный Meander и B_line; резкая смена Meander на B_line;
  чередование блоков по 64 раунда; интерактивный атакующий,
  обучающийся по прошлым действиям защиты.
- Горизонты метаигры 128 и 2048 раундов.
- Три новые независимые калибровки по 40 seed, диапазон
  33000000–33000119, с оценкой на том же основном проверочном банке.
  Три калибровки дают описательную проверку чувствительности и не
  создают интервал, учитывающий всю неопределённость обучения.
- Эпизоды по 100 и 150 шагов: каждый вариант имеет собственные
  40 обучающих и 100 проверочных seed, с началами диапазонов
  34000000 и 35000000 соответственно.

Детерминированные траектории могут повторяться по конфигурации;
одинаковые повторы не добавляют независимой информации. В интерактивном
сценарии методы могут вызывать разные траектории при одном причинном
правиле атакующего. Все дополнительные сравнения носят исследовательский
характер и используют отдельные интервалы без поправки на всю их совокупность.

## Воспроизведение

Настройте [зафиксированный симулятор и окружение](cage_ru.md).
Запускайте команды из корня репозитория. Параллельный сбор может
продолжаться с проверенных контрольных файлов отдельных seed.

```bash
python scripts/collect_cage_bank.py --steps 50 --seed 32000000 --count 400 --workers 8 --exclude-calibration data/cage2 --output results/runs/cage_study/banks/primary50
python scripts/collect_cage_bank.py --steps 50 --seed 33000000 --count 120 --partition calibration --workers 8 --exclude-calibration data/cage2 --output results/runs/cage_study/banks/calibration50
python scripts/collect_cage_bank.py --steps 100 --seed 34000000 --count 140 --partition external --workers 8 --exclude-calibration data/cage2 --output results/runs/cage_study/banks/step100
python scripts/collect_cage_bank.py --steps 150 --seed 35000000 --count 140 --partition external --workers 8 --exclude-calibration data/cage2 --output results/runs/cage_study/banks/step150
python scripts/run_cage_study.py --stage all --workers 8
python scripts/build_cage_study_report.py
python scripts/plot_cage_study.py
```

Новый сбор содержит 14400 эпизодов симулятора и 1098000 внутренних
шагов. [Отчёт](../results/cage_study/README.ru.md) сохраняет выполненные
сравнения, средние значения, интервалы, происхождение данных и массивы
частот выбора пар политик.

Политики, веса ответа, нормировка и бюджет переключения зафиксированы.
При трёх чистых режимах атаки новизна ограничена; переключение не ожидается.
Проверяется адаптация между фиксированными политиками по известной оценённой
модели с раскрытием режима атаки после решения. Новые тактики нападения не
обучаются; журналы атак на действующую сеть не воспроизводятся. Геометрия
целевого множества исключена из расширенного анализа скалярных потерь;
она отдельно приведена в первом опыте.
