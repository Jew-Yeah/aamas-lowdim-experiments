# Экспериментальный раздел для AAMAS 2027

Здесь подготовлен английский LaTeX для официального шаблона AAMAS.
Математическая рукопись находится вне репозитория и не изменялась.

Для основного текста выбран [experiments.tex](experiments.tex): таблица итоговых
потерь и двухпанельный график накопленных разностей. Обе панели используют
**наш метод минус метод сравнения**; отрицательные значения означают меньшие
потери нашего метода. В разделе описаны постановка, порядок наблюдений,
валидация и тест, выбранные методы, статистические интервалы и ограничения.

[supplementary_methods.tex](supplementary_methods.tex) содержит подробный
протокол, компонентные разности и абсолютное векторное расстояние.
[experiment_references.bib](experiment_references.bib) добавляет рекомендованную
официальным репозиторием ссылку на CAGE; запись нужно объединить с общей
библиографией статьи.

Скопируйте английские PDF из [пакета графиков для публикации](../results/cage_adaptation/aamas/README.md)
в каталог `figures/` проекта и добавьте `\input{experiments}` перед заключением.
Шаблон и параметры страницы сохраняются. У рисунков есть подписи снизу и
описания `\Description`, у таблицы подпись сверху. Геометрический рисунок
можно добавить в основной текст, если он укладывается в общий лимит.

Последняя сохранённая рукопись уже занимает восемь страниц содержания плюс
библиографию. Для вставки раздела потребуется отдельно выделить место при
редактировании всей статьи. Эти фрагменты сами по себе не подтверждают
допустимый объём объединённой рукописи; существенные доказательства сохраняются.

Для анонимного рецензирования подготовлен ZIP без ссылки на именной репозиторий.
Команда сборки:

```bash
python scripts/package_aamas_supplement.py --output results/runs/aamas_supplement.zip --ai-statement paper/ai_assistance.md --paper-dir paper
```

Упаковщик проверяет лимит 25 000 000 байт и сохраняет исходные научные данные
и код. См. [требования и рекомендации](../docs/aamas_submission_ru.md) и
[раскрытие применения AI](ai_assistance.md). Публичный GitHub пригодится для
архивной версии после принятия.
