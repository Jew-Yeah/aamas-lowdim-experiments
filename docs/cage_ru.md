# Среда CAGE 2 и быстрый запуск

Эксперимент выбирает полные политики защиты в сценарии производственной сети
официального CAGE Challenge 2 / CybORG. Данные получены из эпизодов симулятора
с открытым исходным кодом. Каждый раунд выбора политики начинает новый эпизод
из 50 шагов. Алгоритм выбирает распределение по шести фиксированным защитам
до раскрытия текущего режима атаки. Потери смеси усредняют исходы полных эпизодов.

## Фиксированные политики

| Политика Blue | Поведение |
|---|---|
| `monitor` | Неизменённый upstream `BlueMonitorAgent`. |
| `react_remove` | Неизменённый upstream `BlueReactRemoveAgent`. |
| `react_restore` | Неизменённый upstream `BlueReactRestoreAgent`. |
| `decoy_cycle` | Циклически размещает штатные ловушки на четырёх заданных важных хостах. |
| `critical_restore` | Поочерёдно восстанавливает `Op_Server0` и `Enterprise2` на шагах 1, 4, 7, …; в остальные шаги наблюдает. |
| `decoy_react` | На сигналы о процессах отвечает восстановлением с ограничением частоты; иначе размещает ловушки. |

Последние три — фиксированные эвристики этого репозитория. Они используют
разрешённые частичные наблюдения Blue. Сигнал о процессе может относиться
к легитимной активности; неудачные размещения ловушек и восстановления
учитываются в результатах. Меню Red состоит из upstream `SleepAgent`,
`RedMeanderAgent` и `B_lineAgent`. Атакующий учится выбирать режим; внутренние
тактики режимов фиксированы. Начальный режим последовательности — Meander.

## Потери и обратная связь

Четыре положительные координаты потерь — компрометация хостов, компрометация
серверов, нарушение работы сервиса и стоимость Restore. Их сумма со знаком
минус на каждом шаге сверяется со штатной наградой симулятора. Основной показатель —
**сумма потерь на один шаг симулятора**, в единицах его награды.

Границы координат `(0.8, 4, 10, 1)` задают априорную векторную нормировку
`sqrt(117.64)`. По 40 калибровочных эпизодов для каждой пары защиты и атаки
оценивают известный тензор векторных потерь. Обновления алгоритмов и выбор режима
атаки используют только эту обучающую модель. Опубликованные банки валидации
и финального теста отделены от калибровки. Происхождение данных сохраняет версию
upstream, диапазоны семян, версии библиотек, хеши исходников и проверки награды.

Все методы получают одну калибровочную таблицу и узнают фактическую метку атаки
после выбора. Такая обратная связь раскрывает режим и позволяет оценивать другие
защиты по модели; для частичных сетевых наблюдений потребовалась бы дополнительная
модель распознавания режима. Внутри эпизода политики Blue получают обычные
частичные наблюдения.

Финальная последовательность начинается с Meander, затем раскрывает и случайно
выбирает три режима. В последней фазе атакующий с экспоненциальными весами обучен
против фиксированной равномерной защиты; 90% вероятности задают обученные веса,
10% — равномерное исследование. Все методы получают одну реализованную траекторию.

## Рекомендуемая реализация

Публичный API `lowdim_games.RecommendedOneSwitchLearner` фиксирует выбранные
на валидации окно 16 и `rho = 0.25`. Алгоритм работает непрерывно и начинает
с равномерного действия. Конструктор:

```python
from lowdim_games import RecommendedOneSwitchLearner

learner = RecommendedOneSwitchLearner(
    tensor, response, horizon,
    weights=weights, initial_prior=initial_prior,
)
# Каждый раунд: p = learner.choose(); затем learner.observe(ell).
# ell — единичный вектор режима, раскрытого после выбора p.
```

`tensor` и `response` описывают обучающую игру. Можно передать веса прогноза
и начальное распределение режимов; оно не заменяет равномерный первый ход.
Выбор по скалярному прогнозу сохраняет исходные оболочку, целевой ответ,
обновление направления, порог переключения и безопасное продолжение.
[Математическое описание](algorithms_ru.md). Валидация обосновывает параметры
для этого CAGE-эксперимента; другой прикладной задаче нужна отдельная валидация.

## Запуск по опубликованным банкам

Команды выполняются из корня репозитория с Python версии 3.10 или выше:

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -e ".[test,cage]"
python -m pytest -q
python -m lowdim_games.cli cage-selected --horizon 16 --seeds 41000000 --output results/runs/cage_selected_smoke
```

Это короткая проверка воспроизводимости с неизменёнными калибровкой, выбранными
конфигурациями и публичным финальным банком. Новый подбор параметров не проводится.
Полный зафиксированный горизонт и 50 семян траекторий используются по умолчанию:

```bash
python -m lowdim_games.cli cage-selected --output results/runs/cage_selected
```

Запускаются выбранный one-switch, настроенные окно и Hedge. Другой горизонт
или набор семян создаёт новый запуск, отдельный от основного зафиксированного
анализа. См. [основной отчёт](../results/cage_adaptation/README.ru.md)
и [протокол валидации и анализа](cage_adaptation_ru.md).

## Повторный сбор эпизодов симулятора

Для сбора нужен чистый upstream зафиксированной версии:

```bash
git clone https://github.com/cage-challenge/cage-challenge-2 .external/cage-challenge-2
git -C .external/cage-challenge-2 checkout 26ce1c1253fa9e2e73f25e6a7f2da32860c11257
```

Сбор отвергает отслеживаемые изменения симулятора. Точные команды для банков
приведены в протоколе валидации. Опубликованных агрегатов достаточно для повторного
выбора политик; внешний checkout нужен только для запуска сборщика симуляции.

## Интерпретация

Аффинная размерность оппонента не превышает двух из-за меню из трёх режимов.
Это свойство заданной игры. Результаты условны относительно конечной калибровочной
модели и фиксированных политик; они не устанавливают гарантий для неизвестных
точных ожиданий симулятора. Они также непосредственно не сопоставимы с обученными
агентами таблицы лидеров соревнования.

Финальное исследование оценивает скалярные потери и не перестраивает векторное
целевое множество. Безопасных переключений нет: для чистых наблюдений из трёх
режимов накопленный остаток новизны не превышает четырёх и меньше стандартного
бюджета. Поэтому измеряется работа быстрого оракула.
