# Игры с низкоразмерным поведением оппонента: эксперименты

Воспроизводимые эксперименты для игр с векторными выигрышами, в которых
обучающийся агент выбирает действие до наблюдения текущего действия оппонента.
Реализованы алгоритм с одним переключением, его явная безопасная процедура,
общий метод на основе выпуклой оболочки прошлых наблюдений, связанный
с Marinov et al. (2026),
и интерпретируемые стратегии распределения ресурсов.

Первая прикладная задача — распределение квот обслуживания между пятью округами
Нью-Йорка на основе открытых данных об обращениях категории Forestry Hazard.
Модель описывает дневное распределение ресурсов. Профили спроса конечной игры
строятся по данным 2019 года; 2021–2022 годы используются для проверки.
Показатели обслуживания также вычисляются на исходном дневном спросе,
отдельно от расстояния до цели в квантованной игре.

Вторая задача — выбор политик защиты сети в официальном симуляторе CAGE 2
при смене режимов атаки. Выполнено 1440 эпизодов симулятора и сравнение
13 методов. Доступны [результаты CAGE](results/cage_reference/README.ru.md)
и [инструкции для воспроизведения](docs/cage_ru.md).

## Быстрый запуск

Требуется Python версии 3.10 или выше. Рекомендуется отдельное окружение.

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
python -m pytest -q
python -m lowdim_games.cli synthetic --q 1 2 --horizon 32 --seeds 42 --plots
```

## Эксперименты

В репозитории сохранены агрегаты открытых данных и сведения об их происхождении.
Проверка сохранённой исторической выборки и основные запуски:

```bash
python scripts/download_nyc.py --years 2019 2021 2022
python -m lowdim_games.cli nyc --profiles 3 6 12 --capacity-ratios 0.6 0.8 1.0
python -m lowdim_games.cli synthetic --q 1 2 3 4 5 --horizon 128 --seeds 20261003 20261004 20261005
python -m lowdim_games.cli geometry --q 1 2 3 4 5 --horizons 32 64 128
```

Загрузчик проверяет и повторно использует сохранённые агрегаты. Параметр
`--refresh` запрашивает новый снимок той же исторической выборки у источника.

Сохраняются настройки в JSON, численные невязки, действия обоих участников
и графики в PNG/PDF. По умолчанию результаты записываются в `results/runs/`.
[Отчёт об опорном запуске](results/reference_run/README.ru.md) описывает
фактически выполненные эксперименты и полученные результаты.

Оракул цели учитывает значения ответа на всей выпуклой оболочке наблюдённых
действий оппонента, включая ранее ненаблюдавшиеся смеси. Сохраняемые невязки
характеризуют точность вычислений с плавающей точкой. Гарантии теоремы в точной
арифметике описаны отдельно в документации алгоритмов. Порог переключения
взят из теоремы без настройки по результатам. На коротких горизонтах
переключение может отсутствовать; тогда алгоритм с переключением совпадает
с общим методом на основе выпуклой оболочки прошлых наблюдений.

## Источники и использование

Алгоритмический источник: [Marinov et al., Efficient Opportunistic Approachability](https://arxiv.org/abs/2602.21328).
Прикладной источник и прецедент использования данных:
[Liu и Garg, Redesigning Service Level Agreements](https://arxiv.org/abs/2410.14825).
Их эксперимент с очередями и сроками обслуживания относится к другой модели;
опубликованные численные результаты не используются как показатели методов
в нашем сравнении.

Код распространяется по [лицензии MIT](LICENSE). Данные сохраняют ссылки на
источники и исходные условия использования; подробности приведены в документации
по данным. Текст статьи и сторонние реализации в репозиторий не включены.
