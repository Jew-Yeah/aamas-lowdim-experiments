# Экспериментальные материалы AAMAS

Текущая часть сосредоточена на полной хронологической траектории переключения
NYC. [experiments.tex](experiments.tex) содержит вставляемый основной раздел;
[supplementary_methods.tex](supplementary_methods.tex) — подробную методику и
дополнительные результаты. Полная рукопись находится вне репозитория;
теоретические утверждения и доказательства сохранены при текущей интеграции.

Разделены две инстанциации master:

- NYC использует отдельно доказанную лаговую безопасную процедуру и
  консервативный **G=1**. Пересечение происходит на раунде 44 из 730,
  затем сохранён весь безопасный хвост из 686 раундов.
- Искусственный тест сохраняет **исходную блочную процедуру и G=6 T^(3/4)**.
  При T=16384 пересечение происходит на раунде 8817. Эквивалентные по выплатам
  метки большой размерности проверяют механизм, а не скорости малой размерности.

Сохранены все пять методов: one-switch, fast-only, lag-safe, окно и отдельный
block-safe. Конечное векторное расстояние и средняя суточная ошибка различаются:
в первом показателе ошибки разных знаков могут компенсироваться. Графики
показывают улучшение относительно fast и положительные разности относительно
более сильных стратегий. Для фиксированных исследовательских рядов после аудита
доверительные полосы и статистическая значимость не заявляются.

Прежний CAGE — зафиксированное дополнительное сравнение: скалярные потери ниже,
чем у настроенного Hedge, и выше, чем у окна; переключений нет. Его наблюдения,
выбор параметров, интервалы и рисунки сохранены.

## Графики и интеграция

Текущие английские рисунки скопированы сюда:

- [Динамика NYC, PDF](figures/switching_nyc_dynamics.pdf) и
  [PNG](figures/switching_nyc_dynamics.png).
- [Тест исходного бюджета, PDF](figures/switching_original_budget.pdf) и
  [PNG](figures/switching_original_budget.png).

Скопируйте PDF в каталог `figures/` рукописи и добавьте `\input{experiments}`.
Сохраняются официальный класс AAMAS, общая библиография, подписи снизу
у рисунков и сверху у таблиц, а также описания доступности.
[experiment_references.bib](experiment_references.bib) содержит записи источников
для общей библиографии. Соответствие объёму определяется по собранной полной
статье; текущий общий объём не проверен. Локальная компиляция обновлённого
проекта завершилась ошибкой из-за недоступности среды встроенного компилятора.

Панель расстояния NYC имеет явный нижний уровень отображения `1e-5`;
исходные массивы сохраняют меньшие значения. Разности направлены **master
минус метод сравнения**, с явным указанием суточной нормы или абсолютного
дисбаланса. Пересекающий ход остаётся быстрым; safe начинается следующим ходом.
Интервалы старого CAGE сохраняют отдельный первоначальный смысл.

## Воспроизведение и материалы рецензента

```bash
python -m pip install -e ".[test]"
python -m pytest -q
python scripts/run_switching_study.py
```

Достаточно базовых зависимостей. В сохранённой среде разработки **пройдены 152
теста**. [Полные результаты](../results/switching/README.ru.md),
[методические пояснения](../docs/switching_ru.md) и
[JSON-протокол](../results/switching/protocol.json) сохраняют параметры, хеши,
аналитические цели, все методы сравнения и массивы каждого хода.

Для анонимного рецензирования следует ссылаться на текущий анонимный архив
вместо именного публичного репозитория. Нужны новые модули переключения,
агрегаты NYC, runner, результаты и рисунки; прежнего пакета только с CAGE
недостаточно. Доказательства теории и Lean, а также текущая методика должны
оставаться отдельными понятными компонентами внутри единого пакета.
См. [рекомендации по подаче](../docs/aamas_submission_ru.md) и
[раскрытие помощи ИИ](ai_assistance.md). Сохраняются указания на руководство
авторов, техническую помощь и ограничения сохранённой истории.
